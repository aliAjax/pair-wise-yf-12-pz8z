# 油站光伏上网电费台

- 行业：石油（油站屋顶光伏）
- 技术栈：Vue3、Vite、TypeScript、Element Plus、Leaflet
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

在原油站地图页基础上升级为上网电费台，数据全部保存在浏览器 localStorage。

## 业务规则

1. **站点档案**：每站登记逆变器编号、并网日期、分段电价（生效日 + 单价）；地图按月显示各站上网电量。
2. **抄表复核**：抄表值低于上期自动挂起补录复核，复核通过前不计入待结算电量；复核可走换表核定（人工核定跨表增量，新表首读保留）、改值确认或驳回。
3. **分段计价**：电价月中调整时，按生效日把表计增量按天拆开计价，不用期末单价覆盖全月。
4. **账单更正**：账单确认后原单不可改，更正月只能生成负向调整单全额冲销，原账单与首次读数保留，冲销后可重新结算。

## 代码结构（三个业务文件 + 界面）

- `src/biz/rules.ts` — 规则层：抄表复核判定、表计增量、电价分段拆分、账单/负向调整单生成（纯函数）
- `src/biz/ledger.ts` — 账本读写：localStorage 持久化、种子数据、全部写操作（响应式单例）
- `src/biz/mapList.ts` — 地图列表交互：Leaflet 地图、账期切换、地图与列表联动
- `src/components/` — 地图面板、抄表复核、账单调整、站点电价四个界面组件
